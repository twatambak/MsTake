# Ms. Take

Jogo em **Construct 2**, de 2020, que começa como um Pong comum e é contado por uma narração em frases na tela. Nasceu do [PongGame](https://github.com/twatambak/PongGame).

## Recursos

- **Introdução** com frases que aparecem letra a letra.
- **Seleção de idioma**, com tradução das frases.
- **Menu** e **tela de opções**.
- **Fase de Pong** com trilha sonora e um gatilho de vitória.

## Como abrir

1. Instale o Construct 2.
2. Abra `Ms. Take.caproj`.
3. Rode pelo botão **Run layout**.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `Layouts/` | `Intro`, `Idioma`, `Menu`, `Opções` e `Pong` |
| `Event sheets/` | Eventos de cada tela e as folhas `Definição das frases` e `Inserção das frases` |
| `Textures/`, `Files/` | Bordas, fundos, ícones e fontes |
